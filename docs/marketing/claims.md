# Claims register

> **Draft, not approved (2026-11-27).** Nothing has been recorded, generated or published ([#176](https://github.com/nulavio/nulavio/issues/176)).

The message house, the trailer and the shorts may say only what is listed here (rule 2). Each script line cites a claim ID. The status was read on 2026-11-27 from the release notes of 160.0.1-0.3 ([CHANGELOG.md](../../CHANGELOG.md)), the [release criteria](../product/release-criteria.md), the tests and the documents linked below.

The status does **not** come from the site's landing page, which describes Nulavio as it is meant to ship ([execution plan](../product/execution-plan.md), "Marketing landing and waitlist"). Its panels are illustrations: their counts and names ("21 blocked", "Easy Coupons") never appear in a video. Every count and interface string shown in a video is the one the recording shows.

Status:

- **implemented**: in the published release 160.0.1-0.3, with a test. Every test case cited here was already in the tag `v160.0.1-0.3` (checked on 2026-11-27 with `git show v160.0.1-0.3:<file>` for each cited case). A document cited beside a test may be newer than the tag when it describes what the release already did (R89 in the residual risks was written on 2026-11-26).
- **planned**: not in a release, or not checked as the release criteria ask. It is always said as "coming soon" or "planned", never shown as working.
- **to confirm**: the sources disagree, so it stays out of every piece until the maintainer says otherwise. No claim has this status today: C11 had it until the decision of 2026-11-27.

A claim is the whole sentence, with its conditions. A script may say less than the claim, never more: a line that drops a condition ("by default", "while it is locked", "the changes it watches") says more than the evidence does.

## Engine line

Any piece that names the engine says it this way, as the [strategy](../brand/strategy.md#correct-use-of-the-name-and-marks) asks:

- en: "Built on Mozilla's Gecko engine. Nulavio is not affiliated with Mozilla. Firefox is a trademark of the Mozilla Foundation."
- pt-BR: "Feito sobre o motor Gecko da Mozilla. O Nulavio não é afiliado à Mozilla. Firefox é uma marca registrada da Mozilla Foundation."

## Keeping it current

Before each render the scripts are checked against this table. A claim that changes status, or whose evidence moves, is updated here first. C11 changes only when [#227](https://github.com/nulavio/nulavio/issues/227) closes. A count with a date (C21) is replaced by the latest run's. Counts that age without a date (tests run, defaults changed) are not used in the videos.
