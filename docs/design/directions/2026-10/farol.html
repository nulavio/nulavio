Guia de integração

Conecte sua conta à API de pagamentos em três passos: crie uma chave, registre um webhook e valide cada evento recebido.

Autenticação

Todas as chamadas usam HTTPS e uma chave de API no cabeçalho Authorization. Gere chaves separadas para testes e produção.

curl https://api.docs.example/v2/pagamentos \
  -H "Authorization: Bearer $CHAVE_API" \
  -d valor=4990 -d moeda=BRL

Webhooks

Cada evento chega assinado. Calcule o HMAC-SHA256 do corpo bruto com o segredo do webhook e compare o resultado com o cabeçalho X-Assinatura antes de processá-lo.

Responda com o status 200 em até cinco segundos. Se não houver resposta, o evento é reenviado com intervalos crescentes durante 24 horas.
