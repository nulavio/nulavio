Install

Fedora

Add the Nulavio repository and install the package:

sudo dnf config-manager addrepo --from-repofile={{repo_file}}
sudo dnf install nulavio

On the first install, dnf shows the repository key and asks whether to import it. Accept only if the fingerprint is this one:

{{key_fpr}}

The same public key is at {{key_url}}. The repository has signature checks on for both the packages and the metadata.

Ubuntu

Add the Nulavio repository, check the key that comes with it, and install the package:

sudo curl -fsSLo /etc/apt/sources.list.d/nulavio.sources {{sources_file}}
sed -n '/^Signed-By:/,$ { s/^ \.$/ /; s/^ //p }' /etc/apt/sources.list.d/nulavio.sources | gpg --show-keys
sudo apt update
sudo apt install nulavio

The repository file carries the public key, and apt accepts only what that key signed. The second command shows the key's fingerprint: go on only if it is the one above. The package brings an AppArmor profile that lets the browser isolate its tabs, as Ubuntu does for Firefox.

Limit: The fingerprint only protects you if you check it through a different path from the download, for example this page opened on another device.

Updates

New versions arrive through sudo dnf upgrade, sudo apt upgrade or the system's software centre. When Mozilla publishes a Firefox security fix, the project's goal is to publish the matching Nulavio within 72 hours.

Limit: In that window, the installed Nulavio does not have the fix yet.

Check a manual download

The same packages, with a SHA256SUMS list signed by the key above, the SBOM and the build manifest, are on the release page on GitHub: github.com/nulavio/nulavio/releases. The key that comes with them counts only if its fingerprint is the one shown above: check it before importing.

gpg --show-keys --with-fingerprint nulavio-packages.asc
gpg --import nulavio-packages.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

What this alpha does not do yet

  • Limit: It does not check download reputation with Google: Google keeps that check for partners. Instead, downloaded installers and scripts open a warning, are never run directly, and are saved without execute permission.
  • Limit: Unlocking profiles with your phone or a FIDO2 security key is not available yet. Protected profiles open with a password, a recovery code or the system keyring.
  • Limit: Fedora only for now.

Remove

sudo dnf remove nulavio
sudo rm /etc/yum.repos.d/nulavio.repo

Your profiles live in your home folder and are not deleted when you remove the program.

Report a problem

Defects: open an issue in the project's repository. Security flaws: write to security@nulavio.net, not to the public tracker.
