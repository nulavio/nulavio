Install

Fedora

Add the Nulavio repository and install the package:

sudo dnf config-manager addrepo --from-repofile={{repo_file}}
sudo dnf install nulavio

On the first install, dnf may first print, in red, Signing key not found: the key is not imported yet, and that is expected. It then shows the repository key and asks whether to import it, and asks again for the same key before it installs the package. Accept only if the fingerprint is this one (dnf prints it without spaces):

{{key_fpr}}
{{key_fpr_plain}}

The same public key is at {{key_url}}. The repository has signature checks on for both the packages and the metadata.

Ubuntu

Download the Nulavio repository file, check it, install it and install the package:

curl -fsSLO --proto '=https' {{sources_file}}
sha256sum nulavio.sources
sudo install -m 0644 nulavio.sources /etc/apt/sources.list.d/
sudo apt update
sudo apt install nulavio

The second command shows the file's SHA-256: go on only if it is this one, and delete the file if it is not:

{{sources_sha256}}

The file carries the public key above, and apt accepts only what that key signed. The package brings an AppArmor profile that lets the browser isolate its tabs, as Ubuntu does for Firefox.

Other distributions (Flatpak)

Nulavio comes to other distributions through Flathub, which keeps it up to date. Until then there is no Flatpak to install: the bundle that came with earlier versions never updated itself, so releases no longer carry it.

Limit: If you installed that bundle, it stays on its version and gets no security fixes: remove it (Remove). On Fedora or Ubuntu, install the package above first; on another distribution, use another browser until Nulavio is on Flathub. To keep your bookmarks and passwords, export them in the bundle's Nulavio first: Bookmarks, Manage Bookmarks, Import and Backup, Export Bookmarks to HTML; and Passwords, the ⋯ menu, Export Passwords. Import them in the package's Nulavio from the same menus, then delete the exported password file, which is not encrypted.

Limit: The fingerprint and the SHA-256 only protects you if you check itthem through a different path from the download, for example this page opened on another device or the release notes on GitHub, which carry both.

Updates

New versions arrive through sudo dnf upgrade, sudo apt upgrade or the system's software centre. When Mozilla publishes a Firefox security fix, the project's goal is to publish the matching Nulavio within 72 hours.

Limit: In that window, the installed Nulavio does not have the fix yet.

Nulavio Companion (Android)

To unlock a protected profile with your phone, install Nulavio Companion on Android 11 or later. The app comes with this release, among the files of the project's release page (github.com/nulavio/nulavio/releases): {{companion_apk}}.

Before installing it, check the certificate that signs it. With Android's build tools, apksigner verify --print-certs {{companion_apk}} must print this SHA-256, which is also at https://nulavio.net/keys/nulavio-companion.der:

{{companion_fpr}}

Android accepts an update of the app only when the same certificate signs it. The app is not on F-Droid yet.

Check a manual download

The same packages, with a SHA256SUMS list signed by the key above, the SBOM and the build manifest, are on the release page on GitHub: github.com/nulavio/nulavio/releases. The key that comes with them counts only if its fingerprint is the one shown above: check it before importing. Run the commands in order and stop at the first one that fails.

gpg --show-keys --with-fingerprint nulavio-packages.asc
gpg --import nulavio-packages.asc
gpg --status-fd 1 --verify SHA256SUMS.asc SHA256SUMS |
  grep -q '^\[GNUPG:\] VALIDSIG .* {{key_fpr_plain}}$' &&
  sha256sum --check --ignore-missing SHA256SUMS

The last command checks the files only if the list was signed by the key {{key_fpr}}. gpg reporting a good signature (Good signature in English) is not enough: it reports that for a signature by any key you already have. Use only the files the last command confirms (OK in English); if it confirms none, do not use the download.

What this alpha does not do yet

  • Limit: It does not check download reputation with Google: Google keeps that check for partners. Instead, downloaded installers and scripts open a warning, are never run directly, and are saved without execute permission.
  • Limit: Unlocking profiles with your phone or a FIDO2 security key is not available yet. Protected profiles open with a password, a recovery code or the system keyring.
  • Limit: Fedora only for now.

Remove

On Fedora:

sudo dnf remove nulavio
sudo rm /etc/yum.repos.d/nulavio.repo
sudo rm -f /etc/nulavio/automatic-updates

On Ubuntu:

sudo apt remove nulavio
sudo rm /etc/apt/sources.list.d/nulavio.sources
sudo rm -f /etc/nulavio/automatic-updates

The Flatpak bundle of an earlier version:

flatpak uninstall --user net.nulavio.Nulavio

Your profiles live in your home folder (the Flatpak bundle's in ~/.var/app/net.nulavio.Nulavio) and are not deleted when you remove the program.

Report a problem

Defects: open an issue in the project's repository. Security flaws: write to security@nulavio.net, not to the public tracker.
