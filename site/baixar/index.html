Instalar

Fedora

Adicione o repositório do Nulavio e instale o pacote:

sudo dnf config-manager addrepo --from-repofile={{repo_file}}
sudo dnf install nulavio

Na primeira instalação, o dnf pode antes mostrar, em vermelho, Signing key not found: a chave ainda não foi importada, e isso é esperado. Depois ele mostra a chave do repositório e pergunta se pode importá-la, e pergunta de novo pela mesma chave antes de instalar o pacote. Só aceite se a impressão digital for esta (o dnf a mostra sem espaços):

{{key_fpr}}
{{key_fpr_plain}}

A mesma chave pública fica em {{key_url}}. O repositório vem com a verificação de assinatura dos pacotes e dos metadados ligada.

Ubuntu

Baixe o arquivo do repositório do Nulavio, confira-o, instale-o e instale o pacote:

curl -fsSLO --proto '=https' {{sources_file}}
sha256sum nulavio.sources
sudo install -m 0644 nulavio.sources /etc/apt/sources.list.d/
sudo apt update
sudo apt install nulavio

O segundo comando mostra o SHA-256 do arquivo: só continue se for este, e apague o arquivo se não for:

{{sources_sha256}}

O arquivo traz a chave pública de cima, e o apt só aceita o que ela assinou. O pacote traz um perfil do AppArmor que deixa o navegador isolar as abas, como o Ubuntu faz com o Firefox.

Outras distribuições (Flatpak)

Em outra distribuição x86_64 com o Flatpak instalado, use o pacote Flatpak que vem na página da versão no GitHub. Baixe-o com a lista de SHA-256 assinada, confira os dois e instale só para o seu usuário:

curl -fsSLO --proto '=https' {{flatpak_url}}
curl -fsSLO --proto '=https' {{release_files}}/SHA256SUMS
curl -fsSLO --proto '=https' {{release_files}}/SHA256SUMS.asc
curl -fsSLO --proto '=https' {{key_url}}
gpg --show-keys --with-fingerprint nulavio-packages.asc
gpg --import nulavio-packages.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
grep -F " {{flatpak_bundle}}" SHA256SUMS | sha256sum --check
flatpak install --user {{flatpak_bundle}}

Só instale se a impressão digital for a de cima, se o gpg disser Good signature e se o sha256sum disser OK para o arquivo .flatpak (ele falha se o arquivo faltar ou não estiver na lista).

Antes de instalar, o Flatpak pergunta se pode adicionar o remoto flathub (https://dl.flathub.org/repo/): o Nulavio roda sobre o runtime org.freedesktop.Platform 26.08, que vem de lá. Na primeira vez são até cerca de 1 GB de download e cerca de 2,4 GB em disco; um sistema que já tem esse runtime baixa bem menos.

Depois ele mostra as permissões do Nulavio, que são estas:

  • network, ipc, wayland, fallback-x11 e pulseaudio: navegar, mostrar janelas e tocar som.
  • devices (todos os dispositivos) e pcsc: para câmeras, chaves de segurança FIDO2 e cartões inteligentes, como no Flatpak do Firefox da Mozilla.
  • xdg-download: a pasta Downloads, e nada mais da pasta pessoal. Os perfis ficam em ~/.var/app/net.nulavio.Nulavio.
  • D-Bus: FileManager1 para mostrar um download na pasta, NativeMessagingProxy para gerenciadores de senha como o KeePassXC, a11y.Bus para a acessibilidade, org.mozilla.nulavio.* para abrir uma janela no navegador que já está aberto e NetworkManager para saber se o computador está on-line.

Abra o Nulavio pelo menu de aplicativos. Para torná-lo o navegador padrão, escolha Nulavio em Aplicativos padrão, nas configurações do sistema, ou rode:

xdg-settings set default-web-browser net.nulavio.Nulavio.desktop
  • Limite: O pacote Flatpak não se atualiza sozinho. A cada versão nova, baixe e confira o pacote dela do mesmo jeito e instale-o por cima, com flatpak install --user --reinstall e o nome do arquivo novo. Os perfis ficam. Enquanto você não instala, o Nulavio fica sem as correções de segurança da versão nova.
  • Limite: No Flatpak não há os perfis cifrados no disco nem o modo nulavio run --confined, porque precisam de programas fora do sandbox, nem as integrações com o KRunner, o KDE Connect e as atividades.

Limite: A impressão digital e o SHA-256 só protegem se você conferir por um caminho diferente do download, por exemplo nesta página aberta em outro aparelho ou nas notas da versão no GitHub, que trazem os dois.

Atualizações

As versões novas chegam pelo sudo dnf upgrade, pelo sudo apt upgrade ou pela loja de programas do sistema; o pacote Flatpak, só instalando o da versão nova. Quando a Mozilla publica uma correção de segurança do Firefox, a meta do projeto é publicar o Nulavio correspondente em até 72 horas.

Limite: Nesse intervalo, o Nulavio instalado ainda não tem a correção.

Nulavio Companion (Android)

Para desbloquear um perfil protegido com o celular, instale o Nulavio Companion num Android 11 ou mais novo. O app vem com esta versão, entre os arquivos da página de versões do projeto (github.com/nulavio/nulavio/releases): {{companion_apk}}.

Antes de instalar, confira o certificado que assina o app. Com as ferramentas de build do Android, apksigner verify --print-certs {{companion_apk}} precisa mostrar este SHA-256, que também está em https://nulavio.net/keys/nulavio-companion.der:

{{companion_fpr}}

O Android só aceita uma atualização do app assinada pelo mesmo certificado. O app ainda não está no F-Droid.

Conferir um download manual

Os mesmos pacotes, com a lista SHA256SUMS assinada pela chave acima, o SBOM e o manifesto do build, ficam na página da versão no GitHub: github.com/nulavio/nulavio/releases. A chave que vem junto só vale se a impressão digital for a mostrada acima: confira antes de importar.

gpg --show-keys --with-fingerprint nulavio-packages.asc
gpg --import nulavio-packages.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

O que este alpha ainda não faz

  • Limite: Não consulta a reputação de downloads no Google: o Google reserva essa verificação a parceiros. No lugar dela, instaladores e scripts baixados abrem um aviso, nunca são executados direto e são salvos sem permissão de execução.
  • Limite: O desbloqueio de perfis pelo celular ou por chave de segurança FIDO2 ainda não está disponível. Perfis protegidos abrem com senha, código de recuperação ou o chaveiro do sistema.
  • Limite: Só Fedora por enquanto.

Remover

No Fedora:

sudo dnf remove nulavio
sudo rm /etc/yum.repos.d/nulavio.repo

No Ubuntu:

sudo apt remove nulavio
sudo rm /etc/apt/sources.list.d/nulavio.sources

O Flatpak:

flatpak uninstall --user net.nulavio.Nulavio

Seus perfis ficam na sua pasta pessoal (os do Flatpak, em ~/.var/app/net.nulavio.Nulavio) e não são apagados ao remover o programa.

Relatar um problema

Defeitos: abra uma issue no repositório do projeto. Falhas de segurança: escreva para security@nulavio.net, não para a lista pública.

O Nulavio é construído sobre o motor Gecko da Mozilla. O Nulavio não é afiliado à Mozilla. Firefox é marca registrada da Mozilla Foundation.
