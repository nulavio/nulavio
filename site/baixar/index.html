Instalar

Fedora

Adicione o repositório do Nulavio e instale o pacote:

sudo dnf config-manager addrepo --from-repofile={{repo_file}}
sudo dnf install nulavio

Na primeira instalação, o dnf mostra a chave do repositório e pergunta se pode importá-la. Só aceite se a impressão digital for esta:

{{key_fpr}}

A mesma chave pública fica em {{key_url}}. O repositório vem com a verificação de assinatura dos pacotes e dos metadados ligada.

Ubuntu

Baixe o arquivo do repositório do Nulavio, confira-o, instale-o e instale o pacote:

curl -fsSLO --proto '=https' {{sources_file}}
sha256sum nulavio.sources
sudo install -m 0644 nulavio.sources /etc/apt/sources.list.d/
sudo apt update
sudo apt install nulavio

O segundo comando mostra o SHA-256 do arquivo: só continue se for este, e apague o arquivo se não for:

{{sources_sha256}}

O arquivo traz a chave pública de cima, e o apt só aceita o que ela assinou. O pacote traz um perfil do AppArmor que deixa o navegador isolar as abas, como o Ubuntu faz com o Firefox.

Limite: A impressão digital e o SHA-256 só protegem se você conferir por um caminho diferente do download, por exemplo nesta página aberta em outro aparelho ou nas notas da versão no GitHub, que trazem os dois.

Atualizações

As versões novas chegam pelo sudo dnf upgrade, pelo sudo apt upgrade ou pela loja de programas do sistema. Quando a Mozilla publica uma correção de segurança do Firefox, a meta do projeto é publicar o Nulavio correspondente em até 72 horas.

Limite: Nesse intervalo, o Nulavio instalado ainda não tem a correção.

Conferir um download manual

Os mesmos pacotes, com a lista SHA256SUMS assinada pela chave acima, o SBOM e o manifesto do build, ficam na página da versão no GitHub: github.com/nulavio/nulavio/releases. A chave que vem junto só vale se a impressão digital for a mostrada acima: confira antes de importar.

gpg --show-keys --with-fingerprint nulavio-packages.asc
gpg --import nulavio-packages.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

O que este alpha ainda não faz

  • Limite: Não consulta a reputação de downloads no Google: o Google reserva essa verificação a parceiros. No lugar dela, instaladores e scripts baixados abrem um aviso, nunca são executados direto e são salvos sem permissão de execução.
  • Limite: O desbloqueio de perfis pelo celular ou por chave de segurança FIDO2 ainda não está disponível. Perfis protegidos abrem com senha, código de recuperação ou o chaveiro do sistema.
  • Limite: Só Fedora por enquanto.

Remover

sudo dnf remove nulavio
sudo rm /etc/yum.repos.d/nulavio.repo

Seus perfis ficam na sua pasta pessoal e não são apagados ao remover o programa.

Relatar um problema

Defeitos: abra uma issue no repositório do projeto. Falhas de segurança: escreva para security@nulavio.net, não para a lista pública.

O Nulavio é construído sobre o motor Gecko da Mozilla. O Nulavio não é afiliado à Mozilla. Firefox é marca registrada da Mozilla Foundation.
